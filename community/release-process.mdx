---
title: Releasing ORAS Projects
sidebar_position: 40
---

Each ORAS project defines and maintains its own release process alongside its code.
Follow the instructions for the project you are releasing:

- [ORAS CLI release instructions](https://github.com/oras-project/oras/blob/main/RELEASING.md)
- [ORAS Go library release instructions](https://github.com/oras-project/oras-go/blob/main/RELEASING.md)

For another ORAS project,
check its repository README or contributing guide for release instructions.
If the process is not documented,
ask the project's maintainers in the [ORAS Slack channel](./community_resources.mdx#joining-the-slack-channel).

Organization-wide expectations for release managers and project governance are documented in the ORAS community repository:

- [Release process governance](https://github.com/oras-project/community/blob/main/governance/RELEASE-PROCESS.md)
- [ORAS project governance](https://github.com/oras-project/community/blob/main/governance/GOVERNANCE.md)

Use the project-specific release instructions for commands,
automation,
and approval requirements.
