# Go

The ORAS Go client library is maintained in the [oras-go repository](https://github.com/oras-project/oras-go). Its guides and API references are maintained alongside the source code.

| Version | Module | Status | Guides | API reference |
| --- | --- | --- | --- | --- |
| v3 | `github.com/oras-project/oras-go/v3` | Release candidate | [v3 documentation](https://github.com/oras-project/oras-go/tree/main/docs) | [v3 API](https://pkg.go.dev/github.com/oras-project/oras-go/v3) |
| v2 | `oras.land/oras-go/v2` | Maintenance | [v2 documentation](https://github.com/oras-project/oras-go/tree/v2/docs) | [v2 API](https://pkg.go.dev/oras.land/oras-go/v2) |

Migrating from v2? See the [v3 migration guide](https://github.com/oras-project/oras-go/blob/main/MIGRATION_GUIDE.md).

For runnable examples, see the [v3 package examples](https://pkg.go.dev/github.com/oras-project/oras-go/v3#pkg-examples) or the [v2 package examples](https://pkg.go.dev/oras.land/oras-go/v2#pkg-examples).
