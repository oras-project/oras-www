# oras logout

Log out from a remote registry

```bash
oras logout [flags] <registry>
```

## Examples

Log out from a registry:

```bash
oras logout localhost:5000
```

Log out from a registry with a custom auth config path:

```bash
oras logout --registry-config ~/.config/oras/auth.json localhost:5000
```

## Options

```
  -d, --debug                         debug mode
  -h, --help                          help for logout
      --registry-config stringArray   auth config path
```
